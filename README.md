# One-Star Review of Something Essential

A single-line deadpan one-star review of water, the everyday essential with no taste, no colour and no calories that we are nevertheless always told we are not drinking enough of. `main.ts` writes exactly that one line to `$OUTPUT_DIR/entry.txt` (default `/output`), with a read-back check to confirm what landed on disk is the line itself. Run it with `node main.ts`; the output is one line of 126 characters with no trailing newline.
